# ¿Qué es un programa informático?

Un programa informático es un conjunto de instrucciones ordenadas y escritas en un lenguaje de programación que le indican a un dispositivo que acción tiene que ejecutar para realizar una tarea específica

# Diferencia entre código de fuente, código objeto y código ejecutable

El código fuente es el conjunto de instrucciones escritas por un programador usando el lenguaje de programación, mientras que el código objeto es el resultado de traducir el código fuente a lenguaje maquina y el código ejecutable es el archivo final en lenguaje maquina, generado tras unir el código objeto con las librerías necesarias.

# Etapas del desarrollo del software

* Análisis de requisitos: Se definen las necesidades del usuario
* Diseño: Se crea la arquitectura técnica del sistema
* Codificación: Los programadores traducen el diseño en código fuente funcional utilizando los lenguajes de programación
* Pruebas: Se evalúa el software para detectar y corregir errores.
* Despliegue: El código ejecutable se instala en el entorno final para que los usuarios puedan utilizarlo.
* Mantenimiento y evolución: Se realizan actualizaciones continuas para solucionar fallos, mejorar el rendimiento o adaptar el programa a nuevas necesidades.
